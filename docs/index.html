02 / SEU PROJETO, SUAS ESCOLHAS

Uma base.
Quatro caminhos.

Banco e documentação são independentes. Escolha no prompt ou passe flags para automatizar a geração.

A · POSTGRES + OPENAPI

API completa

CRUD demonstrativo, migrations, journal, schemas Zod e Swagger UI em /docs.

--database --openapi
B · POSTGRES SEM DOCS

Persistência pronta

PostgreSQL, migrations e journal. Valide entradas com parsers manuais.

--database --no-openapi
C · SEM BANCO + DOCS

Servidor documentado

Servidor enxuto com Swagger e Zod para seus próximos endpoints.

--no-database --openapi
D · BASE MINIMALISTA

Servidor enxuto

Express, TypeScript e middlewares de segurança, sem banco ou docs.

--no-database --no-openapi
+

CRUD inicial é opcional. Com PostgreSQL, escolha se quer começar com `/items`. Sem PostgreSQL, essa pergunta não aparece. Use --no-crud para omitir o exemplo.

04 / DESENVOLVIMENTO

Adicione uma rota.
O app encontra.

Crie um arquivo com sufixo .route.ts, exporte o prefixo e o router. O carregador descobre o módulo no desenvolvimento e na versão compilada.

●  routes/products.route.tsTypeScript
import { Router, type Request, type Response } from 'express';

const router = Router();

/** Prefixo do recurso. */
export const routePath = '/products';

/** Lista os produtos disponíveis. */
function listProducts(_req: Request, res: Response): void {
  res.json({ data: [] });
}

router.get('/', listProducts);
export default router;
✓  Registrada automaticamente em GET /products
1
Crie o arquivo

Use products.route.ts dentro de routes/.

2
Defina o prefixo

routePath escolhe onde o router será montado.

3
Exporte o router

Ele é carregado antes do handler 404.
